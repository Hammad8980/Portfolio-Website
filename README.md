# Portfolio Website

A modern portfolio website with React frontend and Node.js backend.

## Project Structure

- `frontend/` - React + TypeScript + Vite + TailwindCSS
- `backend/` - Node.js + TypeScript + Express + MongoDB

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

## Features

- Projects showcase
- Experience timeline
- Contact form
- RAG chatbot (coming soon)

## Tech Stack

**Frontend:**
- React 18
- TypeScript
- Vite
- TailwindCSS
- Framer Motion
- React Router

**Backend:**
- Node.js
- TypeScript
- Express
- MongoDB
